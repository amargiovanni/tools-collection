# GO-2026-5856 — Go stdlib go1.26.4 (embedded in TypeScript 7 native compiler)

**Status:** Accepted — 2026-08-07
**Date drafted:** 2026-08-07
**Drafter:** Claude (cra-evidence) | **Decider:** Andrea Margiovanni (2026-08-07)

## Finding

- **Component:** Go stdlib go1.26.4, embedded in the `tsc` binary shipped by
  `@typescript/typescript-darwin-arm64` (transitive of `typescript@7.0.2` — dev dependency)
- **Source:** grype scan of compliance/sbom/v1.7.0.cdx.json, 2026-08-07
- **Severity:** Medium (per grype; Go advisory)
- **Summary:** Vulnerability in the Go standard library version used to build the
  TypeScript 7 native compiler binary (tsgo). Fixed in Go 1.25.12 / 1.26.5.

## Exploitability in context

- **Is the vulnerable code path reachable in this product?** No — same context as
  GO-2026-4970: local dev/CI type-checker, not part of the shipped static site, no
  attacker-controlled input.
- **Exposure:** build-time only (developer machines and CI runners).
- **Existing mitigations:** shipped product is static HTML/CSS/JS; no server runtime.

## Decision (Accepted)

- **Action:** accept (time-boxed) — resolved when dependabot bumps `typescript` to a
  build on a fixed Go toolchain. Re-review at next release or 2026-09-07.
- **If accept or mitigate:** re-review by 2026-09-07; ADR: [0002](../../docs/adr/0002-accept-unfixable-buildtime-and-base-image-cves-timeboxed.md)
