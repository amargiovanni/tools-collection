# EAA scope — Tools Collection

**Status:** Draft — scope confirmed by Andrea Margiovanni, 2026-08-07.

Tools Collection is a free, open-source, consumer-facing website run by an
individual maintainer. It is not a public-sector body (Directive (EU)
2016/2102 does not apply) and it is not, in the maintainer's assessment, a
service in an EAA-mandated category (e-commerce, banking, transport, etc.).

**Posture: voluntary conformance** with WCAG 2.2 level AA (EN 301 549 for web
content), adopted as project policy in the repository `CLAUDE.md`. Statements
in this directory describe that voluntary posture and are not an admission
that the EAA applies. That scope call is a legal determination recorded here
and revisable by counsel.
